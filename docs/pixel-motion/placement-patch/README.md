## 原生后台隐藏人工步骤（上游PR/上线前仍须完成）

在普通浏览器打开网站并开始播放，录屏同时显示前台页面及浏览器标签。记录目标data-frame及时间；切到另一个普通标签页或最小化至少5秒，再返回。需要实际观测document.visibilityState/hidden的原生变化及目标帧停止；建议DevTools Performance录制或只读console记录事件时间、hidden值和帧号（不要自行dispatch事件或重定义属性）。返回后观察2秒，应按250ms正常播放，无快速追帧。保存完整录屏和时间记录；失焦暂停、逻辑单测和单次前后截图不能代替原生hidden证据。
