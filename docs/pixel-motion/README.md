## 本机重启

在本工作区运行，已有服务运行时不要再启动或结束占用端口的其他进程：

```powershell
npm run build --prefix frontend -- --outDir ../build/pixel-motion
node scripts/pixel-motion/preview.mjs
```

启动器先检查3204/4204，繁忙即拒绝，不杀进程；使用私有合成库配置，首次启动才生成新测试库和随机账号。当前本机沿用已有依赖和Python环境，没有安装或升级依赖。新克隆须按项目/仿真原指南准备依赖与Python，真实试飞仍需要原参考引擎，不能仅凭前端构建宣称可试飞。
