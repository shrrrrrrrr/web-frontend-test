# 第四轮交付：视觉样板精修

日期：2026-10-03。沿用「晴空观测站」，本轮只精修学生公共壳、探索首页与课程地图，完成后停在视觉验收阶段。

## 基线与修改范围

- 起点为第三轮 `d503fde`，素材基线为 `727f8b7`；开始时工作区干净，没有回退或重建项目。
- 原仓库只读引用仍为 `49c179eed0656b34d8b5a03491c8afd9a9d1de77`；唯一推送目标为 `shrrrrrrrr/web-frontend-test`。
- 后端、仿真、依赖和锁文件未变；首页数据组织、课时进度、报告/作品状态、权限清理和实验返回规则未变。
- 所有验收课程、章节、长标题和学生记录均为隔离临时 SQLite 中的合成数据，没有写入开发数据库。正式章节配置仍为空，未分组课时照常显示。

## 完成内容

**地图场景**：章节浮岛、共用平台与课时停靠点组合为连续场景。桌面节点高低错位、按编号蛇形前进，减少重复卡片框线；平板与窄屏使用纵向路线，选中详情就近展开。节点仍是原生按钮，按真实课时顺序支持 Tab、Enter 和 Space。金色「当前学习」与青绿色选中态分开；已有完成状态单独显示。连线随节点实际位置绘制，装饰不接收鼠标事件，不添加锁关。

**信息与首页**：课程信息、资源、回放、排课、课后任务、实验关联与取消原因保持原入口。首页保留第二轮待办模型及第三轮层级；其他待办默认折叠，1440×900 首屏仍能看到主动作和第一张课程卡入口，正文没有缩小。

**学习伙伴**：默认收起为 44px 固定底栏，长页面滚动后仍可找到。展开、收起、重开与 Escape 均支持键盘；保留原提问路由和课程上下文。底部安全留白跟随实际高度，聚焦滚动也留出距离；层级低于通知、菜单和弹窗。没有新增聊天浮窗、模型、记忆或代答能力。

浏览器检查还复现了 390px 学生实验页原有的 8px 横向溢出：原实验根容器的栅格负边距缺少容器内边距。本轮仅给 `/glider` 的学生壳补充响应式内边距，不裁切控制、不修改实验主体或其他角色。

**网页图片**：保留全部 PNG 母版和生成记录，新增 21 个最近邻缩放、无损 WebP 派生文件。编码后逐 RGBA 像素核对，包括透明边缘；不以模糊压缩图像。统一 `srcset/sizes` 支持 DPR，背景图计入 cover 裁切所需的有效宽度。首页横幅优先，首张封面 eager，后续封面和浮岛 lazy；保留宽高占位、后端封面优先和失败回退。开发素材预览使用派生图并提供母版链接。
