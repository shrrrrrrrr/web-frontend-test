# 第一轮：可运行功能框架

## 范围与实现

新实现位于独立 `app/` Git 仓库；保留上级设计资料。仅新仓库允许提交与推送，原项目引用 SHA 为 `49c179eed0656b34d8b5a03491c8afd9a9d1de77`。

学生登录默认 `/explore`，强制改密优先。一级导航为探索地图、实验室、成长档案。探索地图顶部展示由任务接口状态筛选的下一次学习任务，优先退回和进行中任务，其次按已有截止时间；不产生新进度或新门槛。课程列表由后端按当前账号过滤。

课程地图 `/courses/:id` 中每个节点对应接口中的真实课时，使用服务端进度。取消课时显示取消原因。独立章节配置当前为空，无中间章节页，未分组课时不丢失。课程资源与回顾仍可访问。

课时保留回顾、知识卡片和练习、报告与结构化反思、导师评审。补回本课时任务与作品入口，作品和报告分别保存。作品表单直接读取任务对应的报名关系，不再允许学生在作品表单里随意换课程。只有最新作品退回后可提交新版本。

实验室 `/lab` 用注册表管理实验，目前只有原滑翔机。独立进入不选择任何课程，调用原接口时不附加关联；来自课程时校验课程/课时后携带关联。来源链接仅接受站内课程地址，返回时恢复 `stage`。试飞不会触发作品或学习完成接口。复用原参数、物理引擎、结果和历史记录接口。

成长档案保留原有档案与反思入口，增加作品、积分与徽章入口。奖励演示有余额、明细、库存与条件、详情、二次确认、取消、结果和记录、徽章获得状态及详情。兑换重新读取余额和次数，有请求去重和浏览器跨标签页锁；保存失败不报告成功。真实奖励适配器将来实现同样的 `load/redeem` 契约。

学习伙伴可以收起、重新打开，并进入原学习助手页面；从课程页面进入时带课程上下文，实际可提问范围和启用状态由接口决定。不新增聊天存储、模型配置或实验数据读取。

## 业务核对及差异

| 核对事项 | 最新源码结论 | 本轮处理 |
| --- | --- | --- |
| 作品 / 报告 | `works` 与 `lesson_learning_reports` 独立；版本及评审独立 | 不合并；同时保持入口 |
| 报告前置条件 | `learningGate.canSubmitLessonReport` 只要求课堂回顾和已发布卡片全部完成；当前不要求作品先提交 | 沿用当前实现，不擅自增加“必须先交作品” |
| 练习次数 | 当前学习服务仅一次作答；卡片按顺序完成 | 保留接口规则与提示 |
| 截止 | 当前作品提交控制器没有按截止日期禁止提交 | 展示接口截止时间，不额外禁止；最终由服务端判定 |
| 地图顺序 | 有课时 `sort_order`，无确认的章节归属 | 使用空章节配置，保留全部课时 |
| 独立实验 | 后端只在提供 `course_id` 时校验报名关系；旧前端强制选课 | 移除前端额外门槛，无需新增后端能力 |
| 助手能力 | 此 SHA 已包含可配置 AI 服务与规则回退，较早期项目说明更新 | 读取 `enabled` 和 `origin`，不承诺已启用模型 |
| 奖励 | 未找到积分兑换/徽章业务路由；练习 `points` 是题目分值 | 独立演示，不将成绩当积分 |
| 仿真回放 | 原引擎输出指标、航迹图、遥测图和 trace，三维 trace 播放器尚待原项目集成 | 保留结果图和历史视频，不重写引擎，不声称实现新的三维播放器 |

## 权限、缓存和状态

- 后端是最终授权边界；不新增或放宽任何后端权限。
- 恢复会话时先等待 `/auth/me`，不直接显示缓存用户的业务页。
- 学生每次导航、窗口重新获得焦点及可见页面每 30 秒校验账号和课程集合。集合变化卸载重载当前内容；403/404 隐藏旧内容并提供重试。没有后端推送，撤回发现存在最多约 30 秒的轮询延迟；任何新请求仍由后端立即鉴权。
- 网络错误不展示上次成功缓存作为当前结果；提示重试。任务与作品列表、课程回顾补齐加载/错误状态。
- 账号停用/会话失效清除凭证并跳到登录提示。跨标签页切换账号会重新加载，避免混用页面和账号。
- 无报名课程、无课时、卡片未发布、下一阶段未解锁、待评审、退回、新版本、文件上传失败均有对应说明。
- 报告和作品的文字草稿仅保存在当前浏览器；键含账号和课程/任务等标识，附件不持久化。存储异常会显示保存失败。不会导入旧的未按账号隔离草稿。
- 旧 `/dashboard`、`/courses` 对学生显示探索入口；原课程、课时、任务、作品、通知链接保留。其他角色仍走原页面和守卫。
- 桌面网格在窄屏改为单列，侧栏可折叠，表格可横向滚动。本轮无新增复杂动画或插画。

## 接口分类

除奖励外，所有学习与账号数据均来自复制的真实 API 实现。浏览器测试使用独立临时数据库中的合成数据；这与奖励的浏览器演示数据不同。没有正式积分后端，没有实际礼品发货或正式徽章颁发。

正式奖励和章节尚缺产品定义；奖励还缺后端支持。其余已确认的本轮交互可以由当前接口完成。原初始化脚本不包含“星海远航”正式课程及知识卡片，正式课程数据需另行提供或由导师后台配置。
