## 已接入

金币从0开始，服务端本人账本流水是唯一事实源，顶部、课程中及“我的”显示同一余额。课时按原全部学习任务口径及最新approved报告的有效整数评分一次结算，1分=1枚，0分也结算一次；后续改分、报告新版本、重新发布/报名不重算。金币不依赖课时徽章是否配置；徽章仍保留自身定义条件。

签到按服务器北京时间，连续第1天5枚，之后每天+1，第6天及以后10枚，中断一天重置为5。浏览器不能传日期、连续数或金额。月历只读单月真实记录，支持月份切换和内部滚动；日期不做无用按钮。真实明细每页20条，来源保留首次报告ID/版本/分数和安全快照，失效来源不提供课时链接。

显式鉴权POST核对支持历史首次结算与服务恢复；GET摘要不发币。进入页面、课时原地状态回读、课程变化、恢复焦点/可见、联网及午夜读取最新状态。迟到响应、账号切换、未知提交结果和读取失败不会用演示数据或假0冒充真实账户。

旧IndexedDB演示初值120、旧签到、明细、兑换、reset和outbox均保留，演示礼品区域明确显示独立演示余额。演示消息仍写原`demo_exchange_events`及管理员“演示”通知，不影响真实账本。没有正式礼品、价格、库存或配送实现。

日常备份示例（停止当前教学服务后使用不存在的新目录）：

```powershell
npm run teaching -- stop
npm run teaching -- backup --to .local/自己选择的新备份目录
npm run teaching -- start
```

恢复只到不存在的新目录：

```powershell
npm run teaching -- restore --from .local/自己选择的备份目录 --data .local/新的恢复演练目录
```

恢复目录包含原端口配置，未核对端口前不要启动并覆盖当前服务。不要手工复制运行中WAL主文件代替一致备份。

代码回退不等于数据库回退：新增表可以留在旧代码旁；新账本出现正式记录后，不能用旧备份覆盖并丢失流水。应保留新库、备份后做前向修复。生产部署不在本步授权范围。
