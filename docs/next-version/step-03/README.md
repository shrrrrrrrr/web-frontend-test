## 启动

在 `C:/Users/shr/Desktop/nmg前端/app` 执行：

```powershell
npm run build:teaching
npm run teaching -- start
```

已有服务运行时无需重复 start。`start` 只打开既有库并执行增量迁移，不 init、seed 或重置。不要对 `.local/teaching` 执行 `db:init` 或 `teaching init`。前台运行命令用于诊断；需要后台启动时用 `Start-Process node -ArgumentList 'scripts/teaching.mjs','start' -WindowStyle Hidden`，把 stdout/stderr 留在私有 `.local` 中。

原开发账号凭据留在既有私有环境，不把新增密钥/数据库/上传文件放进 Git。所有测试账号与本图集内容均为隔离合成测试，不是正式课文或学生成果。

## 备份与恢复

本轮先仅停止新服务，并把数据库、uploads、feedback 和稳定私有配置一致备份到 `.local/teaching-before-step03-20261008`，再重启。该备份原有 1 项缺失附件引用已如实保留，不虚造文件。

日后备份使用新的独立目标目录：

```powershell
npm run teaching -- stop
npm run teaching -- backup --to .local/teaching-backup-唯一时间戳
npm run teaching -- start
```

恢复先写到**不存在的独立目录**，不覆盖教学环境：

```powershell
npm run teaching -- restore --from .local/teaching-backup-唯一时间戳 --data .local/teaching-restore-唯一时间戳
```

恢复副本私有配置中的端口需要选空闲端口，然后 `npm run teaching -- start --data .local/teaching-restore-唯一时间戳`。本轮实际恢复副本 `.local/step03-restorecheck-20261009` 使用 4225/3195，健康 200、45 表原字段记录一致、完整性 ok、外键错误 0，最后已停止副本；教学环境仍在 4184/3154。

迁移 021 只增加定义、授予与演示事件表；新库 schema 同步。应用回滚可保留兼容的新表；不直接删除库或下迁移。若必须恢复更早业务状态，应先另做当前一致备份，在恢复副本核验后再由用户决定切换。
