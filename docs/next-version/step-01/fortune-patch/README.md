## 算法与有限池保证

4 等级 × 3 图案 × C(6,2) 个不重复宜组合 × 4 忌 = **720** 个完整组合。宜组合按候选顺序规范排列，不将交换两个宜项算作新的组合。

固定版本 `campus-fortune-v2` 与账号 ID 的 SHA-256 派生偏移 `offset` 和与 720 互质的步长 `step`。取北京时间日历日期的整数日序号 `day`，计算 `rank = (day × step + offset) mod 720`，用混合进位一一对应到组合。

因为 step 与 720 互质，720 天遍历全部组合，循环边界也不会和前一天相同。保证相邻日完整组合不同；单个等级或建议可能重复，720 天后完整组合会重复，不声称无限不重复。不同账号可能抽到同样内容；只读取认证本人，不以结果不同充当权限隔离。此算法是稳定伪随机轮换，不是安全抽奖。版本升级首次采用 v2 结果，不承诺沿用 v1 当日组合。

没有进程缓存、数据库写入、奖励存储访问或成绩耦合。金币/礼品/徽章仍是原本地演示，没有开始签到或后续奖励功能。
