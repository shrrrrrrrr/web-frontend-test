## 真实能力、演示与剩余限制

- 真实接口：原课程与学习来源校验、环境检测、试飞创建、记录列表/详情、结果文件及旧视频签名；作品列表、详情、版本及课程有效性复核。没有新增业务接口。
- 本地演示：积分、兑换、徽章保持上一轮明确的演示标识与原配置。飞行不自动完成课时、提交作品或发放积分。
- 回放边界：新试飞不生成视频；trace API 封装仍在，前端逐帧回放渲染器尚未实现。本轮没有 Three.js/WebGL 或伪装试飞的循环动画。学生页无视频时只说明本次可查看数值和图表。
- **后端授权限制仍未解决**：作品列表、详情、下载 API 对学生主要判断本人归属，未同时校验课程发布与有效报名。前端按授权课程限定列表、详情额外核验、课程变化清理，仅是显示边界；直接调用 `GET /api/works`、`GET /api/works/:id`、`GET /api/works/:id/download` 的课程有效性缺口仍存在。本轮没有发现可读取其他学生作品的证据，不能写成跨学生访问。后续应按工作区《作品课程有效性-后端待办.md》单独处理。
- 课程变化沿用已有进入/焦点/可见性/30 秒检查及提交、返回时核验，不宣称实时推送。离线无法确认撤回时沿用已有提示和服务端提交校验。
- 历史试飞 DTO 没有课程/课时字段，结果区只显示确实返回的记录、时间和参数；顶部说明当前进入来源，不猜测旧记录课程归属。
- 正式课程内容、章节、实验关联和奖励规则仍待确认；测试配置不能当成正式设置。公共组件的 Ant Design 弃用提示与静态 message 提示、共享包大小提示仍存在，本轮没有升级依赖。
