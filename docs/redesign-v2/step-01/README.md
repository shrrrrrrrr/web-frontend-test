## 本步交付

- 平台暂定名“PBL 科创平台”，登录、账号服务、奖励与维护端使用校园外壳；本地得意黑字体及官方 OFL 许可。普通教师仍只读，导师、管理员原功能和首页保留。
- 学生登录首先选择后台授予的课程，只有一门也不绕过。选择页只有课程入口及搜索，不加载跨课程待办；没有选课/退课操作。
- 课程直接进入 `/courses/:courseId` 地图；侧栏含关卡地图、实验室、成长档案与返回课程选择。当前课程完全来自 URL，支持刷新、直达、新标签。
- 宇宙地图有真实课时节点、连续 SVG 路线、编号、当前状态、键盘操作和真实详情。桌面宽幅，手机用独立纵向场景与底部详情抽屉。待办、安排、课程说明、资料、回看和任务/作品入口仍在课程中。
- 校园、宇宙横图、纵图、透明飞船共四张生成母版，配响应式无损 WebP。用户指出初版不够像素风后，已重新生成粗像素版本；不是给实拍加滤镜，也不是把完整生成图片当页面。
- `/me` 为账号级身份、奖励与服务入口；积分、徽章、兑换继续明确为本地演示，沿用 IndexedDB 和同账号 provider，切课不重置。
- 实验、作品、报告、反思、档案及过渡助手页均在当前课程范围内。课时来源返回保留 stage/cardId，自由实验只绑定课程，不造课时，不自动提交作品或判定完成。
- 滚动后的固定返回、失效数据清除、课时授权恢复“重新检查”、草稿恢复、附件局部失败继续可用。平台旧猫咪移除；课程侧栏直接进入真实提问页，第二步才替换为机器人浮窗。

## 真实接口与必要后端改动

根据新版总指令，本步允许修改自己的后端。新增学生专用适配入口 `/api/course-spaces/:courseId/...`，复用原控制器而不复制学习、评分、仿真或奖励规则。服务端先核验本人 active 报名和 published 课程，再核对 URL、查询参数、JSON 或 multipart 中的真实对象归属。即使学生同时有两门课，也不能在 A 地址读写 B 的对象。

服务端收窄实验历史、作品和档案集合，过滤在数量限制之前进行；档案能力聚合只使用可归属当前课的记录。补上旧作品/试飞读取的课程有效性检查。其他角色原接口和职责保留。详见作用域表。

**没有新增数据库字段或迁移。** 复用 course_id、enrollment_id、lesson_id 等现有关系；未运行用户业务库初始化，未修改 `.env`、真实学习数据或模型配置。原仓库固定引用 SHA 为 `49c179eed0656b34d8b5a03491c8afd9a9d1de77`，本步没有向原仓库写入、推送或创建 PR。仿真算法、评分、奖励事务及依赖锁文件不变。

## 配置、旧数据与明确边界

- 品牌和字体集中在 `frontend/src/student/space/identity.js`。`COURSE_PRESENTATIONS` 仅显式绑定 courseId；正式课程 ID 确认后再替换配置。`courses.theme` 仍是教学分类，未改成视觉枚举。
- 正式章节和实验关联未提供。正式 `EXPERIMENT_ASSOCIATIONS` 仍为空；`V2_TEST_ASSOCIATIONS` 仅配合标注为 sample 的 9001 使用。未分组课时仍显示。不按标题猜主题或实验，不增加解锁门槛。
- `cover_image` 的同站 `/assets/`、`/uploads/` 引用经前端来源检查；其他地址使用主题图。私有附件仍由后端决定是否可读，前端不能以图片地址绕过授权。教师完整封面/章节/文案编辑器留第三步。
- 旧作品、任务链接通过真实对象定位课程；旧全局实验、档案等没有课程来源时先回选择页并说明。**未绑定课程的旧试飞/作品保留原值、没有批量迁移**：旧本人 API 读取仍可用，课程集合不纳入；本步未新增无归属历史浏览页。无法可靠归属课时/作品的旧成长事件不硬分给课程，也不作为当前课程能力聚合依据。
- 助手读取现有 enabled/provider 能力；过渡入口 `/courses/:id/assistant`。本步未接新模型、自动读取实验、聊天记忆、机器人浮窗或代写能力，也未重新验收外部付费 provider 的回答质量。
- 课时、试飞、档案、作品等内部主体先保留原功能与浅色阅读区；进一步视觉统一、六角色头像、机器人、可编辑文案交接在第二步。完整维护端编辑与上传工作区在第三步。当前没有新增这些功能，也不承诺这些步骤已完成。
