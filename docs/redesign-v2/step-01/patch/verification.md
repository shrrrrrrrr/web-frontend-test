## 字体证据

- 官方发行 `v2.700`，标签提交 `37357262e9928e147436fa3ea401ed2ee560c139`；Round OTF、ZIP、交付 WOFF2 与许可均记录 SHA256：[font-source.json](font-source.json)。官方下载接口遇到速率限制后，使用同一官方 release 资产链接取得原包。
- 已有 fontTools 4.66.1 + Node 内置 Brotli 转换；没有安装或升级依赖。7934 个字形轮廓与 advance width 逐一相等，cmap/name/OS2 相等；静态 500，无 fvar。
- 浏览器实际请求 `/fonts/chill-reunion/ChillReunion-Round.woff2`；额外绕过缓存读取同一路径，验证 `wOF2` 签名、200 状态、1,912,304 字节和文件 SHA256。不是用重命名文件替代。
- 9 个页面/浮层、24 处文字通过 `CSS.getPlatformFontsForNode` 验证真实 `寒蝉团圆体 Round / ChillReunion_Round` 字形：登录标题/标签/输入/按钮、课程选择标题/搜索/课程名、我的标题/说明/数字、礼品浮层、地图标题/课时/测试说明、课时正文以及执行导师/管理员/只读教师。
- 原生搜索框的文字位于浏览器 Shadow DOM，检查其实际编辑节点。记录 computed style、FontFace loaded/500、资源和真实 glyphCount；保留符号 fallback，不只检查 font-family 或 fonts.check。
