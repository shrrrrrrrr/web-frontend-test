# 内容字段映射与填写位置

基线 5777e98；未收到明确交回的用户改稿，继续原 registry，前两版编辑页冻结。本表根据当前课程/学习控制器、schema、上传策略与学生组件核对后建立，表单仅针对教学字段，不由系统 ID 批量生成

| 字段 | 维护入口 | 学生显示位置 | 权限与兼容 |
| --- | --- | --- | --- |
| courses.title / description | 既有课程创建、编辑与课程详情维护区 | 选择卡片、课程信息 | 导师负责范围/管理员；名称必填、说明可清空，原字段 |
| driving_question / story_line / materials_needed | 课程介绍 | 课程信息区 | 原可选字段，不补示例，不清理学习草稿 |
| courses.theme | 原课程编辑 | 原教学主题说明 | 保持教学语义，不作为 UI 主题 |
| presentation_theme / cover_image | 课程显示 | 课程卡片、侧栏、阅读背景、头像许可 | 最小受控 campus/voyage，新旧课程缺省校园；私有封面需鉴权读取 |
| course_chapters.title / sort_order | 课程详情章节与课时区 | 地图章节区域 | 原来无实体；本轮最小新表，未分组旧课时保留，不改变权限和 progress |
| lessons.chapter_id / title / description / teaching_tip | 对应课时编辑 | 地图详情、课时学习 | 章节须同课程；名称必填、说明/提示可清空；原排课和卡片入口保留 |
| tasks.title / description | 对应课时任务文字 | 原任务要求与作品入口 | 补最小文本更新，不改 task_type/require_upload/截止/课时/评分历史 |
| knowledge_cards.key_points / common_mistakes / content | 原知识卡片编辑 | 对应卡片的关键要点/常见误区/正文 | 复用已有字段和原练习历史限制，不新增同义系统小字输入框 |
| resources.lesson_id / title / description / resource_type | 教学资料逐文件上传、已有资料编辑 | 公共资料及对应课时资料 | NULL 为公共；本课时+公共，不能混入另一课时；保留原对象下载/删除与解析状态 |
| course_replays.lesson_id / title / description | 原专用回放上传/编辑 | 课堂回顾视频 | 复用签名流，补同课归属，500MB；不作为普通资料直链 |
| course_experiments.lesson_id / stage / card_id / label / enabled | 课程详情实验关联区 | 自由实验及精确学习阶段入口 | 仅 glider，同课同卡；新增最小持久化，不修改仿真、作品或完成判定 |
| uiCopy 系统条目 | 独立 JSX 与新版可编辑 HTML | 导航、操作、权限/保存/错误等 | 不开放给课程维护者；稳定 ID/显隐不重编号，教学快照不写业务库 |

本轮维护必填名称上限 120 字；课程/课时说明与故事、材料、任务要求上限 10000 字；驱动问题 1000、课时教学提示 2000。原卡片/练习字段使用原编辑器及其限制，不能把新名称上限误套到所有历史对象。空说明保存为 NULL 并停止显示，omitted 字段保持原值，不补示例。必要实体名称不可清空；暂停/取消/归档不因编辑文字而重新开放

## 正式维护与文案改稿分别保存

本轮仅为稳定教学字段提供输入。课程介绍/材料/驱动问题/故事在课程信息区，课时说明与教学提示在真实关卡详情/学习页，任务要求在本课时任务、作品提交上下文；上传资料说明随文件归属显示。若可选 API 字段为空，其说明容器一起隐藏，系统可选小字删除后不补回教师输入框

系统 ID 不作为教学字段，也不由普通内容维护者修改。原 805 个系统条目及显隐/空串状态逐项不变，本轮新增 107 个维护/状态条目；教学 34 个条目仍是合成来源快照，未写入业务库。本轮可编辑 HTML 共 946 项，字段表单数量不由它生成。需要改系统措辞时修改本轮 HTML/JSX 后安全提取；需要改课程/课时教材时从授权维护页面保存，再由学生实际读取

没有交回保存后的用户改稿，因此没有声称已应用浏览器编辑。来源：`uiCopy.jsx` 为当前系统原稿，`step-02/teaching-snapshots.json` 为 34 个隔离测试快照；后者的 objectId 仅用于说明来源，正式实体 ID 从接口读取。前两步 HTML/JSON/快照冻结，保护见 `evidence/copy-audit.json`

可复现的角色入口与填写步骤见 [README](README.md)，格式与上传能力见 [矩阵](upload-formats.md)，最终接口、长度/清空语义与升级范围见 [接口](interfaces-and-migrations.md)。课程/课时编号、草稿 key、报告与作品版本均保留，不把测试材料当正式教材
