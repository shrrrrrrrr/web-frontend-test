# 上传能力与真实边界

维护入口：课程详情 → 课程内容维护 → 教学资料与回放；封面在课程介绍与显示。实际规则由 `GET /api/courses/upload-formats` 返回，本轮只向课程资料增加四种格式。后端仍是最终校验，前端 `accept` 和大小提示不替代权限/结构检查

课程资料共 **22 种扩展名**。新增格式没有扩大作品、反馈、批量学生导入或回放范围。矩阵中的“可提取文字”不是索引必成功或外部模型答案已验收

## 内容校验

- MIME：服务端记录允许变体；`application/octet-stream` 仍必须经过该格式后续校验，不能仅凭后缀放行。MD 接受 text/markdown、text/x-markdown、text/plain；CSV 兼容常见 text/csv、application/csv、text/plain 和 application/vnd.ms-excel
- MD/CSV/TXT：有效 UTF-8，拒绝二进制控制字符和伪装为整页 HTML/script 的文件；CSV 检查引号/分隔结构。不是完整 Markdown/CSV 教材语义验证，非 UTF-8 旧文本需先转换。上传材料始终作为附件下载，不执行其中标签
- XLS：OLE 二进制签名和现有 SheetJS 工作簿解析；不是旧版 XML/HTML 表格更名为 XLS，也不执行宏/公式
- XLSX：ZIP、CRC、Content_Types、工作簿和工作表结构，现有 SheetJS 能识别工作表。展开体积最多 100 MB、包内条目最多 5000，先查大小再展开核 CRC。不是任意 ZIP 改名，不提供 Office 服务或病毒扫描
- 原格式继续既有扩展名、MIME/签名能力；ZIP/三维仅附件，不扩张原解析范围。封面另检查 PNG/JPEG/WebP 容器、尺寸和像素上限；不是完整图像解码/安全扫描，不声称所有损坏图片都能检测

中文原名独立保存在资源 `file_name`，服务端落盘使用随机名；下载使用原名。旧资料缺这些新字段仍按原标题/文件类型降级。前端不展示实际 filesystem 路径；拒绝/超限/持久化失败清理本次孤立文件，替换私有封面仅删除其原拥有文件，不删共享主题资源

## 归属、队列与索引

公共 `lesson_id=NULL`，课时资料/回放必须属于本课程。队列为串行逐文件上传，最多保留 20 项，记录选择时的课程/课时/用途和成功资源 ID。失败项可重试；成功项不重新提交。资料请求具有 UUID＋内容摘要幂等重试，同一编号改变内容会拒绝；专用回放/封面网络结果不确定时先核对列表，不假称已失败或已成功

取消/离开不删除已保存记录；上传中断可能已在服务端完成，需读取列表确认。队列不跨课程、跨会话或后台恢复，无断点续传/远端作业系统。输入和所选文件在当前页面保留，文件不会自动写入本机文本草稿

索引沿用真实 `pending / processing / ready / failed / unsupported`。上传成功和索引成功分别显示；可在原 AI 知识库页面重试失败索引，不重新上传同一资源。没有扫描 PDF OCR、Office 在线编辑、表格/Markdown AI 索引、模型预览或外部服务质量承诺
