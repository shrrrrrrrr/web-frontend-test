## 维护者怎么使用

1. 课程管理 → 创建课程，明确选择界面主题；进入课程详情 → **课程内容维护**。内容工作台中的“课程内容维护”也进入同一页面
2. **课程介绍与显示**：填写名称、介绍、驱动问题等，保存；选择现有封面或另用“封面图片”入口上传。学生在课程卡片/课程信息及对应主题侧栏读取
3. 原 **课时安排** 新增课时、授课人、时间、地点和任务。返回维护区 **章节与课时** 新增/排序章节，编辑课时归属与说明；“设置知识卡片与习题”进入原编辑器。没有正式章节名称时保留未分组
4. **任务要求与教学提示**：修改已有任务文字与课时提示，不修改任务归属或评分规则。学生在关卡详情、学习页和作品提交的上下文读取
5. **教学资料与回放**：先选择公共/具体课时和用途，再选文件。每项记录选择时的课程/课时/用途；改下拉选择不改变已有队列。填写名称/说明后上传。课时页仅读取本课时＋公共资料；课程资源总览显示真实归属
6. 专用 **课堂回放** 选择归属后上传 MP4/WebM；学生在课堂回顾中使用原签名视频流。回放管理/播放/删除仍可使用原“课程回放”标签页；说明和归属也可在新维护区编辑
7. **实验关联**：只可选择已有滑翔机，可配置课程自由入口或具体课时/阶段/卡片。卡片须同课时，只有知识卡片阶段可选；解除关联不删除试飞，不自动提交作品/完成课时
8. 从原 **选课学生** 导入授权测试学生，再发布课程。学生重新进入读取保存后的真实内容。导师失去负责范围会清除维护内容，恢复后“重新读取”必须再次核验；学生失效恢复使用“重新检查”

保存/上传中禁止重复点击；失败保留输入和文件。成功但回读失败保留对象 ID，先重新读取，不重新上传成功项。切标签保留表单，离开未保存输入/待上传文件提醒确认。附件缺失局部提示；课程撤回/账号失效按原权限处理

## 文案修改与正式内容

系统文案在 `frontend/src/content/uiCopy.jsx` 和本轮 [可编辑 HTML](copy-review.html)。912 个系统 ID：805 个旧条目逐项保留，107 个本轮新增；另有 34 个只读合成教学来源快照，共 946 个审阅条目。它们不是 946 个教师填写框。HTML 修改后必须保存下载文件或导出 JSON，再交回路径；浏览器中未保存的编辑不会应用

```powershell
.venv/Scripts/python.exe scripts/extract-copy-edits.py "已保存改稿.html" --baseline docs/redesign-v2/step-03/copy-baseline.json --out test-results/copy-proposed.json
```

安全提取只报告差异/冲突/非法条目，不执行 JSX/HTML，也不写业务库。必要权限和操作含义仍需核对。教学内容由导师/管理员在上面的真实字段填写，34 个快照不自动导入；完整显示块只去最后的句号，输入和原始保存文本不变

## 三步状态与停止边界

第一步提供北航平台与课程独立空间、地图视觉样板、实际字体和关卡设施；第二步完成课程内学习/作品/实验/档案视觉、六头像、机器人、登录地图交互与文案交接；第三步完成真实维护填写、资料上传及学生读取，相关回归见验证记录

尚待课程负责人提供：正式名称、介绍、章节与归属、课时教材、任务/提示、资源/回放与实验关联。用户后续文案改稿尚未应用。外部模型答案质量、真机/软键盘、多浏览器和生产部署未验证；未建设 Office/PDF 阅读器、OCR、资料执行/三维模型预览、聊天长期记忆或奖励发放后台。新主题、机器人动作、原仓库 PR、生产部署均不自动开始
