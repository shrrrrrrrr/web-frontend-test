## 本步页面

课程内课堂回顾、知识卡片与练习、报告与反思、导师反馈，以及作品列表、提交、详情与版本记录使用统一阅读面板。学习、实验、成果页分别使用独立舰舱、观测舱、行星基地场景；正文、状态、路线、表单和图表均为真实 DOM。课程 ID、草稿键、学习门槛、一次作答、版本和评审规则保持原样。

六角色头像由唯一 PDF 六页对齐后原创生成，与新静态机器人及三场景一同完成母版、透明边缘和响应式资源，再接入网页。仅显式 voyage 测试课程展示六角色；未知课程保持校园主题。人物不附带能力分数、职业或学习权限。

右下角机器人直接打开当前课程浮窗，课程侧栏不再提供整页提问入口。跨同课程页面保留本次临时问答与未发输入；关闭不终止请求。课程、账号及权限范围变化后清理上下文，迟到响应隔离。手机有遮罩、焦点与窗口高度处理，常驻入口静态避让当前按钮。详见 [头像与会话契约](storage-and-session.md)。

## 真实接口、演示与尚缺内容

| 项目 | 本步接入与边界 |
| --- | --- |
| 课程、学习、作品、报告、反思、导师反馈、档案、试飞 | 真实 `/api/course-spaces/:courseId/...` 接口；滑翔机仍为原 reference 引擎与七参数。实验不自动提交作品或报告。 |
| 课程头像 | 新增最小真实偏好表与 GET/PUT；本人 active 报名和 published 课程才能读写。无 localStorage 成功替代。 |
| 助手 | 真实 enabled/provider、检索引用、错误和授权处理。业务测试使用隔离 HTTPS 回环 provider，回答明确标注本地测试；不等于外部模型质量验收。日常隔离预览默认未启用，明确展示真实状态。 |
| 积分、徽章、礼品 | 账号统一的 IndexedDB 本地演示，保留醒目标记与原事务规则；没有正式发放、扣分、兑换或发货。 |
| 文案教学快照 | 来自新建合成验收课程的真实 API，供改稿与映射，不作为真实教材，也不写回用户课程。 |
| 正式内容 | 正式主题 courseId、章节、教材、实验绑定尚未提供；测试 9001/9002 不冒充正式课程。 |

没有新增服务器聊天历史、多轮记忆、自动读取试飞数据、代写能力、物理算法、奖励后端或教师维护表单。

## 本机启动

```powershell
cd C:\Users\shr\Desktop\nmg前端\app
npm run build
npm run preview:v2
```

访问 `http://127.0.0.1:4174`，测试账号 `student_wang / student123`。预览使用每次新建的临时 SQLite 与隔离上传目录，不初始化用户业务库、不覆盖模型配置。API 绑定 `127.0.0.1:3144`。4173 是无关应用，不停止它。

已运行的预览需要先退出它自身的启动终端，确认 4174/3144 释放后再启动；不要按端口盲目终止其他进程。原独立试飞旧链接先引导选择课程，新版自由试飞只固定课程，不伪造 lessonId。

## 用户修改入口与停止点

推荐修改 [copy-review.html](copy-review.html) 后保存下载的 HTML 或导出 JSON 并交回；也可以修改 `frontend/src/content/uiCopy.jsx`。系统文案与教学来源分别标记，803 个稳定 ID 中 769 个为系统文案、34 个为教学字段快照。可选文案关闭或留空后不显示；两份文件同时改同一 ID 会报告冲突，不自动选择覆盖。

第三步将收到人工文案修改后再处理教学填写和上传工作区；本步没有预先生成该表单。视觉是否接受由用户复核，业务验证不代替视觉验收。
