# 头像存储与课程临时会话

## 头像

`016_course_avatar_preferences.sql` 只增加 `course_avatar_preferences(student_id, course_id, avatar_id, updated_at)`，主键为账号和课程，外键继承账号/课程，avatarId 有六值 CHECK。迁移可重复执行，不给既有学生自动选角色、不改学习表。兼容升级在隔离旧 schema 验证两次；用户库没有执行初始化。

`GET /api/course-spaces/:courseId/preferences/avatar` 读取本人偏好，未选择返回 null。`PUT` 仅接受一个 `{avatarId}` 字段，外层核验 student、改密、active 报名及 published 课程；客户端不能指定 userId、URL 或路径。教师和执行导师不能代写，课程内对象范围策略不扩大。

写入一次后回读；写失败显示失败，写已成功但回读失败显示“已保存，最新显示未能读取”，只提供重新读取。序列令牌拒绝失效范围的迟到结果，保存中按钮禁用，UI 不用本地数据伪造跨设备保存。平台账号身份不替换。

## 机器人

会话位于 StudentScope 成功核验后的 CourseExperience，外层 key 为 `user.id:courseId`，不使用 JWT 作 key。各页面 body 的原生命周期与草稿规则继续保留；共享会话在同课地图/学习/实验/作品/档案切换时不重建。

发送只包含本次 question 和当前 course_id，由已有 aiAPI 和后端 provider 执行。DOM 记录是当前课程访问期间的临时回看，未提交输入也只在这次访问内保留，不写聊天数据库、不送过去的回答当模型记忆。

关闭仅改变 overlay，不取消请求、不重发。发送中允许编辑下一条；重复按钮/Enter 不重复请求，失败原问题独立保留且不覆盖新草稿。旧消息滚动位置与是否靠近底部共享保存，有“查看最新回复”。来源按旧兼容模型生成站内动作，下载仍鉴权，回答以文本渲染。

离开课程、换账号、退出、强制改密、停用、报名/发布失效时会话和头像展示清理，读写序列失效；授权恢复重新核验，不恢复旧回答。普通 JWT 轮换不改变账号/课程 key。后端不启用、服务错误、限额、资料改版等有真实说明，没有隐式演示回答。

旧 `/courses/:id/assistant` 和学生 `/dashboard/ai?course_id=...` 核验后 replace 到地图，消费一次打开参数再 replace 移除；后台 AI 原页不受影响。不可访问对象不会猜第一门课程。

## 浮层和可达性

同一共享 overlay 管理 chat/nav/details/avatar，开一个收起另一个。桌面聊天为非模态，Escape 在窗外焦点时也关闭。手机和低高度横屏为模态，遮罩关闭、Tab 约束、底层滚动锁、焦点回机器人；visualViewport 提供键盘高度与顶部偏移。头像窗口置于更高层，避免机器人穿透遮罩。

机器人没有动作动画，滚动/尺寸变化只静态避让当前可点击区域；课程内容底部预留空间。物理手机键盘、屏幕阅读器和外部模型质量仍需要目标设备人工验收，不能将模拟窗口高度等同真机全覆盖。
