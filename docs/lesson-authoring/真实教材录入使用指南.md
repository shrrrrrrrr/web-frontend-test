# 真实教材录入使用指南

本指南对应本轮本地持久教学环境。教材写入 SQLite 和受鉴权文件目录；不是浏览器演示稿。本地教学入口为 http://127.0.0.1:4184 ，尚未部署公网。不要把账号密码写进教材、文案改稿或 Git。

## 1. 使用什么账号，从哪里进入

| 角色 | 可操作范围 | 不可操作事项 |
| --- | --- | --- |
| 管理员 admin | 所有课程教材、课时、卡片/练习、资源、文章；上传回放视频 | 不通过教材编辑改学生答案、评分、金币或签到 |
| 执行导师 academic_mentor | 自己创建或被安排授课的课程，与管理员共用教材维护 | 越界课程不可维护；不能上传回放二进制 |
| 普通教师 teacher | 原有分配学生的只读观察页面 | 没有教材可写控件；直接请求维护和上传也被后端拒绝 |
| 学生 student | 活跃报名且已发布课程的真实教材、原学习流程 | 不可写教材；不能通过前端指定发币金额或完成状态 |

用管理员或负责执行导师登录 → 课程管理 → 打开目标课程 → “课程内容维护” → “可视化填写 / 学生效果预览” → 在“选择要填写的课时”中选择真实课时。选择框支持鼠标和键盘。不要按名称猜测另一课程，先核对课程与课时安排。

“查看学生效果”隐藏维护标记和答案解析。“返回编辑”恢复各区域“编辑这里”。这是共用学生课时展示层的教材预览，没有学生个人答案、完成进度或评审结果；学生操作按钮禁用。预览导航可查看所有教学阶段，不代表学生已解锁这些阶段。普通教师不要借用执行导师账号操作。

## 2. 保存、就绪与发布先分清

1. **保存此处教材 / 保存**：立即写入当前教材对象及真实 ID。没有独立的整课“草稿版本/一键发布版本”。课程已发布且学生有权限时，下次读取可见已保存字段。
2. **教学内容准备中 / 已就绪**：控制原课时准备状态。保存段落、图片、资料不会自动变成就绪；准备中非参观课继续显示原空模板。准备完并核对后，由维护者在“课时标题与安排”明确切换就绪并保存。
3. **知识卡片保存草稿 / 保存并发布**：使用原卡片状态。草稿不在学生课时中显示；发布后按原顺序及解锁规则显示。注意在已有发布卡片上选择“保存草稿”会把它改为草稿，不能误当作独立草稿副本。
4. **课程发布**：课程详情原有发布/撤回操作，独立于本页保存。确认课程完整并已按原规则分配学生后再发布；撤回后学生不再访问教材或旧附件 URL。归档课程不能继续保存教材或上传。
5. **学生完成**：仍由学生原学习流程和导师评审决定。读参观文章、上传教材、切换就绪、预览都不是个人出勤或通关，不自动记满分、发徽章或发金币。

正式录入建议在草稿课程或内容准备中完成，随后核对所有区域，再明确发布/就绪。已发布课程没有整课事务式发布版本：各区域逐次保存会逐次对学生生效，请安排录入窗口，避免学生读到半套教材。

## 3. 三类课时从空模板到可读

### VR 参观课

1. 选择真实参观课，打开“课时标题与安排”，核对参观模板、标题、地点、时间、授课人；安排与内容就绪分开保存。
2. 点击“精彩瞬间说明”，填写活动说明并保存。额外瞬间照片可从该课时下载资料位置原位上传；资源标题、说明、排序决定相册展示。正文使用的图片不会再重复铺成相册。
3. 点击“参观图文正文”区域的“编辑这里”：填写文章标题，逐段点击“添加段落”，填写正文；点击“插入已有图片”或使用该面板的图片上传队列。图片区分标题/替代文字与说明。
4. 上传后真实资源 ID 回填正文块，**还要点击“保存此处教材”**。只有上传成功、没有保存文章块时，文件已在当前课时资料中，尚未正式插入正文；可重新打开后选择已有图片，不用再传一次。
5. 用“上移/下移”调整段落及图片次序。替换图：上传新图 → 在对应图片块选择新资源 → 保存；移除块只移除正文引用，不删除真实文件。需要删资料时，先移除所有正文引用并保存，再在资料页删除。
6. 切换“查看学生效果”，核对全文、图文关联和照片次数。回到学生账号读取核对权限。即使内容就绪，参观目前仍缺个人完成依据，不能把文章阅读当出勤。

### 滑翔机理论课

1. 核对标题、安排、课时说明，填写“学习提示”和“课堂回顾正文”。旧课没有独立回顾字段时，回顾沿用课时说明；以后可分别维护。
2. 在回顾的资料区域原位上传课件/PDF/记录模板，上传队列已经绑定当前课时。文档是下载资料，不冒充正文插图。管理员可在回放区域原位传视频。
3. 点击“知识卡片与练习”打开原知识卡维护。填写标题、摘要、正文、知识要点、易错点、预计时长；明确是否必做，保存草稿或保存并发布。必做属性是教学规则，谨慎修改，不能为测试随意更改真实学生任务。
4. 给每张卡添加练习。填写题型、题干、选项、标准答案及解析。选择题每行一项；多选答案用英文逗号分隔；判断题填 true/false。现在已有题也可点“编辑题目与解析”，更新真实原 ID。
5. 填写“报告填写指导”，从作品任务区域编辑已有任务要求；任务要求不等于报告指导。原任务对象和提交/版本/评审关系保持，不在本轮创建新的业务任务类型。
6. 确需关联滑翔机时，在“实验关联”明确选择当前课时、阶段及可选知识卡；没有关联不会自动标配实验。填写实验操作指导不会建立关联。全部准备好后明确切换就绪，再核对四阶段学生效果。

### 滑翔机实验课

1. 核对实验模板及安排，填写回顾材料、实验操作指导、必要卡片/练习、已有作品任务要求及报告指导。
2. 在实验关联中选现有 glider，选择当前课时和真实学习阶段；卡片入口必须属于当前课时、阶段为知识卡。先保存关联，再用预览核对入口位置。
3. 上传实验记录表、作品模板等下载材料；正文插图目前由参观结构化文章提供，回顾和知识卡正文仍是文本字段，不是任意富文本/HTML 编辑器。
4. 明确切换内容就绪后，以学生账号检查实验进入与返回；完成试飞仍不自动提交作品或完成课时。实验参数、物理仿真和评分规则未改。

## 5. 文件能力与原位上传

通用资料22种扩展名，每件≤50MB；资源可传不等于可在线预览或可被助手解析。MIME/签名/内容校验以服务端为准。Office容器签名检查不等于完整杀毒或任意宏安全执行证明。

| 类型 | 能上传/下载 | 预览能力 | 文字解析/索引 |
| --- | --- | --- | --- |
| JPG/JPEG/PNG/GIF/WebP | 是，≤50MB | 授权图片预览，文章及瞬间图片；封面另≤5MB且不含GIF | 不做OCR |
| PDF | 是，≤50MB | 维护端隔离iframe预览，取决于浏览器；无法预览时下载 | 提取可用文本，扫描版无OCR |
| DOC/DOCX/PPT/PPTX | 是，≤50MB | 本维护工具只下载，不嵌入执行Office | DOCX/PPTX可文字索引；旧DOC/PPT需先转换 |
| TXT/MD | 是，≤50MB，有效UTF-8 | 只下载 | TXT可文字索引；MD不支持该索引 |
| CSV/XLS/XLSX | 是，≤50MB；CSV结构和Excel包校验 | 只下载，不是在线表格编辑器 | 无文字索引 |
| ZIP | 是，≤50MB | 只下载，不在网页解压执行 | 不解析包内文档 |
| OBJ/GLB/GLTF/STL | 是，≤50MB | 只下载；没有通用三维预览器，已有滑翔机实验不是该文件查看器 | 不解析 |
| MP4/WebM作为通用资料 | 是，≤50MB | 下载资料，不冒充课堂回放 | 不做语音转写 |
| MP4/WebM课堂回放 | 管理员专用≤500MB | 既有鉴权流播放 | 不做语音转写 |
| HTML/JS/SVG等未列格式 | 否 | 不开放任意脚本/HTML执行 | 不支持 |

操作：点对应区域上传 → 选件 → 核对队列中的标题/说明、归属和格式 → “上传待处理文件” → 等“上传成功”及真实 ID。原位队列已固定本课时；通用“教学资料与回放”页先选择归属，选择文件后每个队列项固定当时的归属，不会跟着后改下拉悄悄改变。

可同时选择多份通用资料，待处理最多20项；成功/取消的历史项不占待处理名额。失败保留当前页面的文字、文件和上传标识，点“只重试失败项”；通用资料的未知结果可以用原upload_token核对重试，不重复写资源。成功但回读失败时保留 ID，只重新读取列表，不重新上传。回放/封面没有同等通用资源幂等保证，未知结果先核对列表，不能把重复点击称为安全补传。

队列是当前页面内存状态，不是永久浏览器草稿；刷新、退出或关页会丢未上传选件。离开前先保存文字和核对队列。上传成功的真实文件可重登后从资料列表找到；图片先上传再保存正文是两步，不声称一个跨文件/正文的大事务。正文引用中的资源被保护：需先移除正文引用并保存，才能移动归属或删除资料。

## 6. 保存状态、冲突和避免丢稿

| 状态 | 怎么判断 | 下一步 |
| --- | --- | --- |
| 编辑中/未保存 | 控件内容有改动，保存按钮可用 | 保存前不要刷新，离开提示选择取消继续写 |
| 保存中 | 保存按钮显示加载，表单暂禁用 | 等待结果，别并行点多次或切课时 |
| 已保存 #ID | 后端写入及回读成功 | 可预览、刷新或重新登录核对 |
| 写入成功但回读失败 | 警告保留真实ID和输入 | 点该区域“重新读取”；不用再新建或上传；要再改时沿已返回revision和ID更新 |
| 网络/写入失败 | 显示错误，输入保留 | 检查网络后重试；超时不能只凭前端推断未写入，先核对服务端当前记录 |
| 内容已由其他维护者修改 | 服务端409，旧revision不匹配 | 先复制保留本地输入；关闭编辑，点课程维护顶部“重新读取”，核对别人改稿后重新编辑保存；不会静默覆盖 |
| 权限失效 | 后端拒绝、当前受限内容清除 | 重新登录或联系管理员核对负责课程/账号状态；不能绕过课程归属继续写 |

文章、课时、课程、已有任务/资源及原知识卡/练习编辑发送已知修订号。旧API调用者仍可能不带可选revision，本轮没有把它描述为全平台强制锁。不要让两位维护者长期编辑同一课时后盲点保存。

教材临时输入仅在当前页面内存中；没有后台自动保存草稿或跨设备编辑草稿。浏览器后退、刷新和外部关闭前注意未保存提示；保存成功后以重读/重登验证，不以截图或下载的HTML当真实教材保存。可编辑系统文案HTML只用于改系统字，保存下载稿不会写入教材数据库。

## 8. 上线前备份、恢复与边界

本轮实际预览重启过：迁移前一致备份，验证隔离升级/恢复后，接入前再次备份并导入，再恢复原持久教学服务。没有停止全部Node，没有切旧4174、隧道或公网。

本地备份：`.local/teaching-before-authoring-20261010`、接入前恢复点`.local/teaching-before-authoring-activation-20261010`，以及含本次完整图文的交接前备份`.local/teaching-before-authoring-handoff-20261010`。备份内原已有1个缺失资源引用，未造文件掩盖。实际数据库、上传、备份、私有配置、真实教学照片与截图不提交Git。

日常在项目app目录执行，备份目标必须是新的不存在目录：

```powershell
npm run teaching -- stop
npm run teaching -- backup --to .local/自己命名的新备份目录
npm run teaching -- start
```

恢复演练只到新的独立目录：

```powershell
npm run teaching -- restore --from .local/自己命名的备份目录 --data .local/新的恢复目录
```

恢复目录保留原端口配置，启动前核对端口，别抢占现有教学服务。备份是数据库与附件及配置一起保留，不能只复制运行中的WAL主文件。新增迁移023兼容保留原字段，代码回退不等于数据库回退；有新教材、金币或签到后不能还原旧库丢掉新记录，优先备份新库并前向修复。

启动/更新仅用独立教学构建，不init/seed/reset实际库：

```powershell
npm run build:teaching
npm run teaching -- start
```
