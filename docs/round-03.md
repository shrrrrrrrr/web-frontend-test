## 启动与验证

在项目根目录的两个终端分别运行：

```powershell
npm run server
npm run dev
```

访问 `http://127.0.0.1:5173`。已有初始化合成库的测试学生为 `student_wang` / `student123`。不要重置已有数据库；全新安装见 [README](../README.md)。正式配置没有章节和实验绑定时，页面保留未分组课时，不自动添加滑翔机配套入口。

```powershell
npm run test:e2e:round3
```
