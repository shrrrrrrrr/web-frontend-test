## 核实与修复

起始源码审阅确认：AI 的 enabled 初值为 false，读取失败要求刷新；失败被追加为 AI 气泡；任务进度空值被显示成 0，缺少作品独立入口；课程回顾用 Promise.all，一处失败会遮住其他区域，回放地址没有请求顺序保护。这些结论来自本地代码核对，不声称在旧版上重跑了整套浏览器复现。

新界面以稳定账号、角色、课程及对象 ID 建立作用域。没有把 user 对象或 token 变化用作清空条件。真实课程变化使用现有 STUDENT_COURSES_CHANGED；账号边界继续交给 AuthContext、Axios 和 StudentScope。前端隐藏入口不构成权限保证。

真实视频验证曾发现开发环境严格模式重复连接 ref 时，清理操作会使 src 为空；播放等待报告 readyState=0、networkState=0。修复为引用连接时恢复当前地址，普通重渲染不重新赋值；再次实播、跨标签 DOM 同一性及播放时间验证通过。其他早期用例失败涉及检索顺序、多条空值定位、已撤回页面的旧挡板测试前置，均按实际契约调整，没有删掉业务断言。

## 小智的真实能力与限制

当前后端通过配置调用模型，成功返回 `origin: 'provider'`。本轮不沿用旧“仅规则式助手”说法，也不新增配置或模型能力。

- GET `/dashboard/ai/courses` 区分加载、失败可重读、明确停用、无课程和未选择。URL 的 course_id 只在允许集合中命中后选中。课程新增会重取原 GET；无关课程变化保留当前聊天及草稿；当前课程失效清选择、回答、引用并拒绝晚到回复。
- POST `/dashboard/ai/ask` 仍仅发送 `question`、`course_id`。问题 trim 后 1—1000 字，Axios 等待仍为 45 秒。界面只显示一次性等待，没有流式假象、自动重发或新取消接口。
- 引用真实 scope 展示“课程相关 / 课程拓展 / 问题范围说明”，无关拒答仍来自后端。回答按安全文本渲染，保留换行、长词换行，不执行 HTML。
- 仅显示本页内存问答。每次不发送以前的聊天；切课、离开、刷新清记录，不保存到 localStorage/IndexedDB，不新增历史后台。
- 普通失败作为服务错误单独呈现。原问题保留，可主动放回空输入框；等待期间已写新文字时，恢复按钮禁用并解释，避免覆盖新草稿。AI_ACCESS_CHANGED 要重新选课；AI_CONTEXT_CHANGED 保留文本但去掉旧引用，提示重新提问。原服务停用、配置、额度、繁忙及超时文案保留。
- 快速点击有同步在途保护；组合输入法 Enter 不发送；Shift+Enter 换行。新回复不会把正在回看的阅读区强制滚到底，提供“查看最新回复”。不宣称离页后模型执行或计费已停止。

来源保留真实 ref、类型、标题和位置；resource 走授权下载，task 走 `/tasks/:id`，course/lesson/card 返回该课程地图。卡片来源没有 lesson_id，未猜课时深链、未遍历学习包。未知类型、缺必要 ID 时不提供假入口，无来源时不填示例。

## 任务与课程回看

任务列表仍读取 `taskAPI.list({status})`，再核对当前允许课程。pending/in_progress/submitted/completed 仍表示原报告与课时进度计算结果；作品 review_status 独立呈现。报告 rejected 提供第三阶段表单入口 `?stage=2`；报告已通过、作品退回时仍可修改作品。没有任务行的课时继续从课程地图学习。缺失进度显示“暂未提供”，真实 0 保留；截止使用项目北京时间格式。

任务详情成功后 replace 跳课时；临时故障与确认无权限分开。StudentScope 对确认失效对象仍可能显示原全局内容挡板；本轮没有放宽它。筛选、重试、离页或课程变化后，旧响应不覆盖新列表，也不产生迟到跳转。

课程回看先读取并核验 courseAPI.detail；主课程失败不展示旧资料或旧作品，识别现有 400“课程不存在”以及 403/404。回放和作品分别加载、报错和重试，局部 503 不变成“无记录”，不清空其余有效内容。

回放只在选择时调用 streamUrl，使用原生 video controls；现有 expires_in 为 600 秒。A→B、同 ID 重取、离开及失效都有请求序号/媒体清理。错误只提示本段不可播，允许主动重取地址，并通过原范围机制复核，不无限重试。播放不会完成课堂回顾或新增学习进度。0/空时长不渲染孤立 0。

每项下载独立防重；返回 Blob 后再次核验课程才触发保存，失效/离页后不再下载；临时 URL 在使用后或卸载时释放。附件 404 只对当前项报错并沿用定向范围复核，有效课程和聊天继续可见。无文件资料没有假下载按钮。

作品复用 workStatus：历史退回且有新版显示“已修改”，最新退回仍可查看意见并修改。作品、报告没有合并。

## 真实、测试与未完成边界

页面功能均接现有 API。浏览器验证使用独立临时 SQLite、上传目录、合成账号和数据。AI 成功通过本地 HTTPS 兼容 provider → 未修改的真实后端 → 前端完成，provider 返回固定且标注的测试回答；**没有验证真实外部模型的回答质量，也没有读取或覆盖现有 AI 设置、真实学生数据或真实密钥。**

临时 provider 证书、随机密钥、测试媒体和数据库留在系统临时目录，不提交。截图不含密码、token、实际联系方式或完整签名播放地址。

指定故障注入：浏览器拦截课程/任务/回放/作品区域 503、附件 404、媒体 401 过期、缺失进度和未知来源 DTO；延迟真实响应制造竞态。本地 provider 分别返回 429/402/401，并挂起一次响应触发后端真实 30 秒 AI_TIMEOUT。课程发布、报名、账号停用、FORCE_RESET、资料变化和缺少 AI 配置通过临时数据库真实改变，不用伪造成功响应替代。媒体是 ffmpeg 生成的测试画面，通过真实签名流播放。

仍存在的限制：

1. 作品列表后端对课程当前授权的既知缺口未修。此页先核验主课程，并在作品列表返回后再次核验课程才展示本人版本；这只是前端边界，不是后端安全修复。原待办见 docs/archive-backend-todos.md。
2. 课程变化仍靠原有进入/焦点/30 秒检查及请求失败触发核验；没有新增服务端实时推送。失效一经确认即清媒体与内容。
3. AI 没有后台聊天历史、流式接口或执行取消接口；card 引用没有课时定位字段。未擅自补后台。
4. 只验证 Windows Edge 的模拟视口和缩短窗口；没有声称验证真实手机软键盘、Safari/Firefox 或辅助读屏设备。
5. Vite 构建通过，仍提示一个现有公共依赖块大于 500 kB；没有为了消除提示改依赖或做无关拆包。

本轮范围内功能已实现；不包含正式课程制作、真实外部模型验收或新业务。
