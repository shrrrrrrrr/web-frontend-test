## 数据与回退

奖励数据库 `star-voyage-rewards` 的 `accounts` 是按账号的本机唯一来源。合法 v1 localStorage 仅首次导入并保留备份；重置不删除初始化标记，旧标签刷新后使用当前逻辑，不能合并旧版页的新写入。换设备没有同步，清除浏览器数据会丢失演示记录。代码 revert 不等于恢复数据库或奖励数据，任何数据恢复需要另行明确来源与权限。

服务器授权仍是最终边界。课程变化通过既有进入/焦点/定时/失败核验确认，没有新推送协议；确认失效后清理内容，暂时网络失败保留仍有效的填写。前端展示改善不能据此声称完成全部后端安全审计。
