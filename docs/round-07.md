## 统计和数据口径

- 参与课程：档案 `courses` 的 enrollment_id 与现有反思报名映射相连，再与当前可访问 course ID 相交。报名不等于课程完成；仅展示实际存在的 completed_at，不计算推测日期。
- 项目作品：可展示作品按 `parent_work_id || id` 去重。作品迭代：可展示版本中带 parent_work_id 的记录数。列表搜索、课程筛选后的说明只统计当前结果，报告完全不参与作品统计。
- 反思记录：可展示报名下的 reflections，包含独立日志和报告反思，不伪称全部是独立日志。课程评价：同范围的 evaluations 条数，不含报告评审与作品评审。
- 作品评审维度汇总：确认原档案返回的作品集合全部属于当前有效范围时才展示接口 ability；任何作品被范围过滤便显示“暂不可汇总”。不重新平均、不批量读取详情、不生成角色能力排名。缺失分数是“暂无评价”，真实 0 仍显示 0。
- 成长足迹：有 work_id 的事件只保留当前有效作品；同作品已有事件时不再叠加作品兜底提交。反思按有效报名显示；明确 teacher 类型且有 recorded_by 的个人人工记录保留。无对象关联的系统文本隐藏详情并说明范围限制，不按标题或相近时间猜归属。
- 档案读取每个逻辑批次最多三个并发摘要请求，发布前再次核验课程和报名；课程变化触发清除、重读，旧请求不会复活记录。课时和作品详情仅由明确选择进入。

## 真实、演示与接口限制

档案、报名映射、课程详情、课时报告、作品列表/详情、独立反思提交全部使用既有真实 API。验收库中的课程、身份、作品和教学内容为合成测试材料，不是正式“星海远航”课程。积分、兑换、徽章仍为原本地演示，入口明确提示，没有改演示规则或新增积分后端。

服务端仍存在课程有效性缺口：档案、作品/下载、独立反思 API 不完整校验当前发布/报名范围。前端交集与重验只保护页面展示，不能写成后端授权已经修复。未关联成长事件无法可靠归属；报告接口没有全量目录、完整历史或导师姓名；完成日期缺少常规自动来源。详情与后端待办见 [数据边界记录](archive-backend-todos.md)。

独立日志按服务端北京时间每天一次，当天报告反思也计入；没有在前端添加配额算法。错误保留当前页面四个文本字段，离开或刷新即丢失，不能冒充浏览器草稿。成功才提示服务端保存。提交前的核验无法消除最终 POST 前的服务端竞态，仍需后端处理。

| 场景 | 实际结果 / 证据 |
| --- | --- |
| 自动加载、有/无成果、同名不同 ID | 真实 API：两门同名课程分开；初始 2 门课程、4 个项目、1 次迭代、2 条反思、2 条评价。新学生参与 1 门课但成果四项均为 0 |
| 撤回、报名移除、迟到档案 | 临时库真实撤回课程后对应记录与统计减少；移除剩余报名后课程相关五项均为 0；人工个人记录仍保留。延迟旧档案响应也未恢复撤回内容 |
| 归属核验与部分失败 | 注入档案 503 时统计为破折号，已核验课程仍可查询；报名映射 503 时旧档案/统计清除，显示刷新失败；重试恢复 |
| 报告按需与独立状态 | 档案首页和仅选课程时没有课时包请求；选定后仅请求该 lessonId（开发 StrictMode 会重复 effect）。无作品任务课时第 2 版真实报告可看，0 分保留；报告通过不覆盖作品退回状态 |
| 报告锁定、错误及迟到响应 | 真实锁定/未提交状态分别验证；单课时 503 显示错误；换课时后延迟报告不覆盖新选择。卡片调整后已有报告仍可进入原评审阶段回看 |
| 多版本、退回与待办 | 真实作品集合去重；历史已修改/最新需修改分别验证；搜索与课程筛选有效。临时加入 10 个同项目版本，15 条记录仍为 4 个项目、11 次迭代，第二页可达；原详情反馈和修改按钮可用 |
| 反馈与汇总 | 真实未评分显示暂无评价；原 ability 含无效作品时降级。边界注入 0/null 验证真实零与缺失不同；原 SQL 五维 1–5 限制未修改，零值截图明确是契约边界注入 |
| 时间轴 | work_id 相同的提交仅显示一次；未关联的系统文本不泄露旧详情；真实人工记录和有效反思可展开 |
| 独立反思 | 必填验证、键盘实际 POST 成功、服务端数据库写入及档案回读；真实日限额拒绝、提交 503、报名映射失败均保留全部四字段 |
| 反思关联与响应式 | 真实课程撤回只清课程/课时；快速切换课程后旧课时响应不覆盖；无课程禁用提交。三尺寸无页面横向溢出，提交动作未被伙伴/顶栏遮挡 |
| 多角色 | 管理员、导师、教师真实登录核对原档案与导出；添加记录按钮仍限原角色；管理员/导师保留作品管理，教师仍被原路由拒绝 |
