## 已修复的数据与容错问题

1. **存储 getter 拒绝导致组件渲染失败**：适配器接收延迟获取存储的函数，真正访问在可捕获的操作中执行。页面不在 useMemo/render 中直接获取 localStorage。存储对象获取、getItem 读取、损坏 JSON/结构、setItem 写入、removeItem 重置分别产生可解释的错误；不会静默降级为内存存储。若 removeItem 已完成但回读失败，则明确“记录已清除，但余额暂不可读取”，不谎称旧记录仍在。
2. **跨标签顶栏与主体不一致**：学生外壳按账号挂载一个共享 store，顶栏与页面使用同一快照。相关奖励 storage 键、key=null 清空事件、匹配账号的同页事件和返回焦点触发重读；无关账号事件不影响当前视图。最后订阅者卸载时移除监听并使在途读取失效；递增读取编号拦截迟到快照。
3. **重置与兑换交叠**：两种写操作使用同一账号 Web Lock。兑换在获得锁后重读余额、库存和限次，持久化成功才返回记录。重置与兑换相反顺序分别得到实际最终初始值或扣分结果；成功弹窗中的记录若已被其他页重置，会提示“演示记录已变化”。
4. **页面与账号生命周期**：离开奖励页中止尚在等待锁的操作；已完成的持久化不能撤销，但旧页面回调不再显示成功。账号切换或退出使旧 Provider 和弹窗卸载，新账号读取自己的键。提交中只有一条执行路径；同一确认失败重试不会换请求编号。
5. **弹层焦点边界**：除 Ant Design 自身约束外，在奖励弹窗补上 Tab 首尾循环，避免最后一个按钮继续 Tab 时进入浏览器工具栏。此修正仅作用于奖励弹窗。

后台刷新不切换当前标签或重建记录列表，不主动改变滚动位置；暂时读取失败保留旧列表并明确暂停当前条件，不把它误显示为空礼品库。详情中的条件随共享快照更新，确认执行也会再次核对。所有读写仍通过可替换适配层。

## 保留的契约与环境边界

- 存储键仍为 `star-voyage:rewards:demo:v1:${accountId}`，原 v1 余额、兑换及明细继续读取，没有迁移或自动清空。
- 初始 120；笔记本 40 / 库存 3 / 限兑 2；模型 160 / 库存 2 / 限兑 1；贴纸 20 / 库存 0 / 限兑 1。两枚徽章分别固定为演示已获得、未获得。rewardConfig.js 未修改。
- 库存只计算本账号本地记录，不代表全平台库存。初始化是演示初始值，不能被解释为真实发放。没有正式奖励 API，所有积分、兑换、徽章都是本地演示，不读取学习成绩或自动发放奖励。
- Web Locks 可用时，同一浏览器、同源、同账号的合作页面写入串行。无 Web Locks 时保留同步回退；已验证单页回退可操作，但不保证跨标签原子性。不同设备/浏览器也不共享记录。手动改存储或浏览器清除数据仍会改变演示结果，不宣称交易级保证。
- 存储异常通过隔离浏览器的 getter / Storage 方法替换注入；不等于已验证全部浏览器隐私模式。实际验证了已登录运行中的拒绝及拒绝后首次挂载奖励页。登录页本身在全站初始存储禁用时的处理属于后续辅助页面范围，本轮未扩展 AuthContext。
- 长历史截图注入十一条兼容格式记录，仅用于验证分页与换行；不是通过当前限兑规则产生的记录。未修改正式课程配置或真实学生数据。

关键场景的证据：

- 原 v1 合成记录兼容在单测中验证；浏览器实际兑换后刷新仍为 80，换账号为独立的 120；首次兑换记录为空。
- 三种不可兑换状态均通过真实演示适配器出现：积分不足、零库存、两次后达限次。详情、取消、成功、两枚徽章及重置均在三尺寸实拍。
- setItem 故障后余额仍为 120、没有兑换记录；恢复后快速连续点击重试，只产生一个请求编号、一条兑换和一条扣分明细。
- 同一浏览器上下文两个实际标签页接收原生 storage 事件：兑换后两页顶栏与正文均为 80，打开的模型详情从还差 40 变为还差 80；积分明细和兑换记录同步。重置后两页回到 120，当前记录标签保持不变。
- 实际 Web Locks 中人为持有同一把锁，让真实 UI 的兑换/重置依次排队：两种顺序均核对最终 localStorage 与 UI；两页同时尝试最后一次笔记本兑换，只有一页成功，另一页显示原限次原因。
- 焦点返回重读、同页事件及清空事件（key=null 的受控事件）验证通过；多个异步快照交错和卸载后迟到响应在单测中验证，旧值不能覆盖新值。
- getter 拒绝、getItem 失败、损坏数据、removeItem 失败均不白屏或自动删除。重置失败保留确认，恢复后重试成功。getter 在进入奖励页前拒绝也能进入错误状态并恢复。
- 排队期间离开页面，以及另一页退出导致原账号页面销毁，均无旧账号成功提示；新账号不出现旧弹窗。管理员、执行导师、教师不能进入奖励页，没有学生奖励样式污染。
- 390 窄屏连续 Tab 保持在弹窗内部，操作按钮可点击且不被伙伴遮挡；关闭回到详情触发点；背景更新保留标签和滚动位置。
